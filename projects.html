Dual Power Supply System with IoT Integration

Designed and built a hybrid power system using solar generation as the primary source and the grid as an automatic backup. Applied power systems analysis, control logic and embedded system design to take the concept through to a working prototype, with an IoT interface for real-time monitoring and manual source switching.

Dual-Source Energy Manager

A software-first extension of my hybrid solar/grid power project. The planned ESP32 model will use weather inputs to estimate PV generation, simulate battery behaviour and prioritise solar, battery and grid supply. The current work is at the system-definition stage; electrical values are simulated, not live measurements.

PV model: 500 W Battery model: 1.5 kWh Target: ESP32 dashboard
