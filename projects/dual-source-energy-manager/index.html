Dual-Source Energy Manager

A software-first extension of my final-year hybrid solar/grid power system. The aim is to model how a PV array, battery and grid can work together, then make the energy flows visible through a dashboard served by an ESP32.

02ENERGY MANAGEMENT CONCEPT

The planned controller will calculate the available solar power and compare it with the modelled load. It will use the battery to cover a solar deficit while the battery remains above its reserve threshold. The grid will supply any remaining demand.

03DESIGN ASSUMPTIONS

Model parameters

  • PV array rating: 500 W, with a 0.80 performance factor.
  • Battery nominal capacity: 1,500 Wh.
  • Battery state-of-charge window: 20–100%, initially 60%.
  • Charge and discharge efficiency: 95% each.
  • Battery charge/discharge power limit: 300 W.
  • Illustrative daily load: 1.88 kWh, with a 150 W peak.

Planned implementation

  • ESP32 reads hourly solar-radiation and weather forecast data.
  • Energy model advances in 15-minute steps.
  • ESP32 hosts a responsive local dashboard.
  • RGB LED indicates the modelled active source, where supported by the board.
  • Optional ThingSpeak logging for selected summary values.
  • Sensor adapter functions keep model inputs replaceable by future hardware readings.
04ROADMAP
  • Phase 0 · System definition: establish parameters, load profile and plain-English control rules.
  • Phase 1 · Model: implement and test PV, load, battery and source-allocation calculations.
  • Phase 2 · Weather data: connect and validate the forecast-data adapter.
  • Phase 3 · Dashboard: serve live model outputs from the ESP32.
  • Phase 4 · Telemetry: add optional cloud logging and board-specific RGB status.
  • Phase 5 · Sensor-ready upgrade: replace selected simulated readings with hardware measurements and validate the design safely.
05DATA & SAFETY NOTES

Weather data is planned from the Open-Meteo API. The free API is subject to non-commercial-use terms; confirm permission before using a live feed in a public portfolio. Where data is displayed, attribution will be provided as required.

This is an educational simulation, not a certified energy controller. It must not be connected to or used to switch real grid, inverter, battery or mains circuits. A future hardware stage requires appropriate protection, isolation, certified equipment and qualified electrical review.

An INA219 can measure voltage and current; it does not directly measure battery state of charge. A later implementation would estimate SoC from measured current and a battery model.
